# UX spec (DRAFT — wording and sizes to be confirmed with her; see plan Task 1b)

## Tokens
| Token | Value |
|---|---|
| Body text | 28px minimum |
| Tile labels | 40px |
| Button height | 72px minimum |
| Colours | dark text (#111111) on light background (#FFFFFF); accent #0B5CAD (contrast >= 7:1) |
| Cursor | large |

## Home
Greeting with her name ("Good morning, {HER_NAME}"), date and time in large type, five tiles (picture + label):
1. Email  2. Facebook  3. Write a Letter  4. My Downloads  5. Help
and a "Turn off" button.

## Bottom bar (always visible, like the Windows taskbar)
Home (far left, where Start is) | Back | Print | Volume - / + | Help | clock (far right).
Home closes the open app and returns to Home. Double-click works but opens one window; right-click does nothing.
