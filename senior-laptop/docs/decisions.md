## Deferred minors (not fixed)
- 03-remote uses curl before it is installed.
- re-running 04-hardening resets quarantine mode to 0750 until 06 runs again.
- re-runs enable --now do not restart changed services (airlock, usbguard).
- usb-blocked-flag.service has no RestartSec.
- notify_user writes in place so the shell can read a partial file.
- offline/printer polling and Help block the GTK main loop.
- offline/printer messages are only a 10-second toast, no persistent status line on Home.
- Print with no app open still says "Sent to the printer."
- empty HER_NAME gives "Good morning, ".
- .doc/.docx are allowed but nothing can open them (they re-download through the airlock).
- Firefox "Refresh Firefox?" prompt (browser.disableResetPrompt).
- clamd ConcurrentDatabaseReload doubles memory briefly on 4GB.
- airlock follows symlinks in quarantine.
- hidden, .tmp and empty files sit in quarantine with no message.
- verify/run.sh hides why a check failed.
- /tmp noexec breaks debconf apt-extracttemplates (set APT::ExtractTemplates::TempDir).
- Turn off may fail silently without polkit/logind session.
- airlock sandboxing could be tighter (capabilities, syscall filter, address families).
- WebP, GIF and HEIC photos are rejected.
